# Game mechanics

## Shared rules

- Single player only
- 10 targets per round
- 3 shots per volley
- Hit means bagged for review
- Miss means escaped
- Actual deletion happens only after round review

## Game A

One tweet target per volley. The target is assigned one tweet candidate. The player gets three shots. If the player hits it, the tweet is added to the round bag. If the player misses all shots or time expires, the tweet escapes.

## Game B

Two tweet targets per volley. Each target is assigned one tweet candidate. The player gets three shots total. Hitting either target bags its tweet. Unhit targets escape when the volley resolves.

## Game C

Two clay targets per volley. Clay targets are not mapped to tweets. Game C is a non-destructive practice mode and should be blocked from all delete routes.

## Round end

When ten targets have resolved, the game moves to review. Review should display:

- total hits
- escaped targets
- score
- pass line
- bagged tweets
- escaped tweets

## Review ordering

Review tweets in shot order, not chronological order. The review should feel like replaying the round.
